# Roasteira - Artisan Coffee Landing Page

A production-grade, feature-packed landing page for an artisan coffee roasters brand. Built with pure HTML, CSS, and JavaScript — zero frameworks, zero dependencies.

## Project Structure

```
roasteira-landing/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles (responsive, dark mode, animations)
├── js/
│   └── main.js         # All interactivity (slider, form, toast, etc.)
├── assets/
│   └── images/         # Placeholder for local images
└── README.md           # This file
```

## Features

| Feature | Description |
|---------|-------------|
| Loading Screen | Elegant spinner with fade-out on page load |
| Scroll Progress Bar | Top bar showing scroll percentage |
| Sticky Navbar | Glass-morphic blur effect on scroll |
| Dark Mode Toggle | Sun/moon switcher with localStorage persistence |
| Mobile Hamburger Menu | Animated overlay navigation |
| Scroll Reveal Animations | Elements animate in on scroll (Intersection Observer) |
| Count-Up Stats | Numbers animate from 0 when scrolled into view |
| Testimonial Carousel | Auto-rotating slider with dots + arrows, pauses on hover |
| FAQ Accordion | Smooth expand/collapse, one open at a time |
| Form Validation | Real-time email regex validation with visual states |
| Toast Notifications | Slide-in alerts instead of ugly alert() popups |
| Cookie Consent Banner | Dismissible with localStorage memory |
| Back to Top Button | Appears after 500px scroll, smooth scrolls up |
| Button Ripple Effects | Material-style click ripples |
| Smooth Scroll | All anchor links scroll smoothly |
| Keyboard Support | ESC key closes mobile menu |
| Fully Responsive | Breakpoints at 900px and 600px |

## How to Run

1. Extract the zip file
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari)
3. Or open the folder in VS Code and use Live Server extension

5. Process - 4-step alternating timeline
6. Testimonials - Dark section with star ratings carousel
7. FAQ - 5 questions with accordion
8. Newsletter - Validated email form
9. Footer - 4-column grid with social icons
