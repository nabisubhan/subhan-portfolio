A modern, responsive, and interactive personal portfolio website built with HTML, CSS, and JavaScript.

## 🌟 Features
- 🌙 Dark theme with glass morphism effects
- ✨ Animated particle background
- 📊 Animated skill bars
- 📱 Fully responsive mobile design
- 🖱️ Custom cursor glow effect
- 📝 Contact form with validation
- 🎯 Project filtering system

## 🛠️ Tech Stack
- **HTML5** — Semantic structure
- **CSS3** — Custom animations, gradients, glass effects
- **JavaScript** — Interactivity, DOM manipulation, Canvas API
- **Tailwind CSS** — Utility-first responsive styling
